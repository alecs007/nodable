# Security Policy

## Supported versions

Nodable is a client-side application with no server component and no user accounts. Security fixes
are released from `main` and included in the next release.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's
[security advisory form](https://github.com/alecs007/nodable/security/advisories/new), or by email to
[SECURITY CONTACT].

Include the affected version, a description of the issue, and the steps needed to reproduce it. You
can expect an acknowledgement within seven days and an assessment within thirty days. Once a fix is
available, the advisory is published with credit to the reporter unless anonymity is requested.

## Scope

In scope: the published web application and the packages in this repository.

Out of scope: vulnerabilities in third-party dependencies that already have a public advisory, and
issues that require a compromised browser or operating system.
